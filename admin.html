GitHub 自動更新の設定 AUTO PUSH

GitHub の Personal Access Token を設定すると、admin.html から**直接 index.html を書き換え・自動プッシュ**できるようになります。
iPad Safari から使えば、git コマンド一切不要で HP 更新完結。

📝 Personal Access Token の発行手順：

1. GitHub にログイン → 右上プロフィール → Settings
2. 左メニューの一番下 Developer settings
3. Personal access tokens → Fine-grained tokens
4. Generate new token をクリック
5. 名前：shibasaka-admin（任意）
6. Expiration：90日 or 1年（好みで）
7. Repository access：Only select repositories → shibatora0827.github.io を選択
8. Permissions → Repository permissions で Contents: Read and write を設定
9. Generate token をクリック
10. 表示された文字列（github_pat_...）をコピー
11. この画面の "PERSONAL ACCESS TOKEN" 欄に貼り付けて保存

⚠️ 注意：Token は1度しか表示されません。なくしたら再発行になります。
